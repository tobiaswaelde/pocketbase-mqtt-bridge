## 0.1.0

### Minor Changes

- [`29e476c`](https://github.com/tobiaswaelde/pocketbase-mqtt-bridge/commit/29e476c)
  Initial NestJS bridge for publishing selected PocketBase collections to MQTT,
  with environment-based credentials, YAML collection configuration, retained
  state, PocketBase Realtime updates, Docker, CI, and VitePress documentation.

- [`5dd18d5`](https://github.com/tobiaswaelde/pocketbase-mqtt-bridge/commit/5dd18d5)
  Add configurable complete-record, field-only, and combined MQTT payloads.
  Nested JSON values are published as retained field topics and cleaned up when
  a value disappears.

- [`aac0034`](https://github.com/tobiaswaelde/pocketbase-mqtt-bridge/commit/aac0034)
  Preserve primitive arrays as one JSON field value while expanding arrays of
  objects into indexed MQTT field topics.

### Patch Changes

- [`d051ea5`](https://github.com/tobiaswaelde/pocketbase-mqtt-bridge/commit/d051ea5)
  Normalize quoted environment values so `.env` files work consistently in

- [`e370634`](https://github.com/tobiaswaelde/pocketbase-mqtt-bridge/commit/e370634)
  Accept PocketBase dashboard URLs ending in `/_/` by normalizing them to the
  PocketBase server root.

- [`29c0555`](https://github.com/tobiaswaelde/pocketbase-mqtt-bridge/commit/29c0555)
  Make bridge dependency injection explicit so `pnpm dev` starts reliably with
